# Security policy

## Supported versions

Security fixes target the latest stable Rich Markdown Preview release (currently
2.0.x). Older releases should upgrade to the latest stable version; prereleases
and development builds receive fixes through the main development branch.
The extension supports VS Code 1.95 and newer. Contributor Node/npm requirements
are documented in [CONTRIBUTING.md](CONTRIBUTING.md).

## Report privately

Email maintainer Kasun Kodagoda at [kvkrusl@gmail.com](mailto:kvkrusl@gmail.com)
with the subject `Rich Markdown Preview security report`. This is the maintainer
contact recorded in this repository's Git history. Do not put vulnerability
details in public GitHub issues or pull requests. GitHub private vulnerability
reporting availability has not been verified; email is the reporting route.

Include the extension and VS Code versions, operating system, affected component,
expected and actual behavior, security impact and a minimal reproduction using
synthetic Markdown or an isolated fixture. Remove credentials, tokens and private
workspace content. Share sensitive attachments only after agreeing on a private
transfer method with the maintainer. Coordinate disclosure after a fix is available.

If no acknowledgement arrives within seven days, follow up by email. There is no
guaranteed response or remediation SLA. Mailbox monitoring, account-side code/
secret scanning and private reporting configuration require maintainer verification;
local validation does not prove those services are enabled.
